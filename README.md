# Acreage

An Elementor-first WordPress theme for land, farm and rural property listings.

Listings are **not** stored in the theme. They belong to the
[Acreage Core](https://github.com/sanket5257/acreage-core) companion plugin, so
switching theme later leaves every property, photograph and filter term exactly
where it was.

## Install

1. Appearance > Themes > Add New > Upload Theme, choose `acreage.zip`, activate.
2. Install and activate Acreage Core. Without it there is no Farms post type.
3. Install Elementor. The free version is enough.
4. Optional: activate `acreage-child` instead, so your changes survive updates.
5. Appearance > Demo Content > Import demo content.

Full notes are in `readme.txt`.

## Updates

Releases published here are offered to installed copies automatically. The
updater compares the release tag against the `Version:` line in `style.css`, so
bump that (and `Stable tag:` in `readme.txt`) before tagging, and attach the
built zip as a release asset.
